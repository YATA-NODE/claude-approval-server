# セル属性 corpus の件数表(案C Phase 0、単一の正)

本表が corpus 規模の**唯一の正**。設計文書の本文に出てくる「5 系 × 各種別 3 件」等の概算は参考値であり、
食い違う場合は本表が優先する。Phase 0 冒頭で固定し、以後は**増やす方向にも減らす方向にも動かさない**
(動かす必要が出たら中止条件の判定に入り、ユーザー承認へ送る)。

## 用語

- **種別**: 画面の種類。T1〜T5 の 5 つ。
- **状態軸**: 真正サンプルが取りうる描画状態。再描画 / 折返し / 幅 / 属性欠落 の 4 つ。
- **攻撃系**: 敵対サンプルの生成手段。①〜⑤(+ ⑥、下記)。
- **件数 = fixture 件数**であって録画本数ではない。1 本の録画から複数フレームを fixture 化してよい
  (各 fixture が生成元 payload とフレーム境界を個別に持つ限り)。

### 種別

| ID | 種別 | 備考 |
|---|---|---|
| T1 | claude ツール承認(ラベル有り) | Bash / Write / Edit / Read / Grep = BOX_LABELS を持つ |
| T2 | WebFetch(ラベル無し) | 終端マーカー不在で現在は非検出 |
| T3 | MCP(ラベル無し) | 現在 tool='Unknown' / args='' のまま転送される残余 |
| T4 | タブ式 | AskUserQuestion 複数 / codex 複数質問 |
| T5 | 確認画面 | Review your answers。戻す一手の回帰の根 |

### セルの 3 状態

各セルは次のいずれかで埋める。**空欄と 0 を作らない**。

1. **数値** = 必須 fixture 件数。
2. **N/A** = その組み合わせが意味を成さない。**理由を 1 行必ず添える**。
3. **未観測** = 探索したが該当フレームが corpus に存在しなかった、という**結果**。
   計画値としては数値を置き、探索して見つからなければ未観測へ書き換え、**探索方法を併記**する。
   採否表ではその状態軸について「保証なし」と明示する(黙って 0 にしない)。

## 真正サンプル(検出必須 = 偽陰性 0 を要求する側)

出所で真正と決める(= 実機で CLI が実際に描いた枠の録画)。検出実装の規則は参照しない。

| 種別＼状態軸 | 再描画 | 折返し | 幅 | 属性欠落 | 小計 |
|---|---|---|---|---|---|
| T1 claude ツール承認 | 1 | 1 | 1 | 1 | 4 |
| T2 WebFetch | 1 | 1 | 1 | 1 | 4 |
| T3 MCP | 1 | 1 | 1 | 1 | 4 |
| T4 タブ式 | 1 | 1 | 1 | 1 | 4 |
| T5 確認画面 | 1 | 1 | 1 | **1(必須)** | 4 |
| | | | | **小計** | **20** |

- **幅**: 既存録画は cols=120 のみ。**cols=80 での再録画が必須**(幅依存のシグナルを誤って
  採用しないため。master plan「cols/rows は認定対象外 = 幅非依存のシグナルのみ採用」)。
- **属性欠落**: T5 は実測済みの回帰の根なので**必須**。T1〜T4 は該当フレームが無ければ
  「未観測」+ 探索方法(全フレーム走査で bg セル 0 の枠フレームを探した、等)を記録する。

### ⑥ 真正枠 × 敵対的内容(枠内注入)

master plan の R8-B001(真正枠の中身への注入耐性)を件数化したもの。上記 5 系の**外**に置く
(攻撃の狙いが「枠の偽装」でなく「枠内 args のすり替え」で別物のため)。

| 種別 | T1 | T2 | T3 | T4 | T5 | 小計 |
|---|---|---|---|---|---|---|
| 枠内注入 | 3 | 3 | 3 | 3 | **N/A** | **12** |

- **T5 が N/A の理由**: 確認画面は args を抽出も転送もしない(画面状態の判定のみ)ため、
  注入すべき対象が存在しない。
- 注入内容 = 改行 / 罫線 / 類似ラベル / タブ印 / 全角・Unicode / 省略記号 を args に含める。
  合格条件は**抽出結果が独立オラクルと完全一致**すること(独立オラクルの定義は master plan を参照)。

## 合計と中止閾値

| 区分 | 件数 |
|---|---|
| 真正 | 20 |
| 敵対(5 系) | 75 |
| 境界ケース(部分再描画) | 5 |
| ⑥ 枠内注入 | 12 |
| **総計** | **112** |
| **中止閾値** | **224**(総計の 2 倍) |

**中止閾値の意味**: 実際に生成・検証した fixture の累計が 224 件に達しても Phase 0 の
exit 条件を満たせない場合、**スコープを勝手に縮小せず設計へ差し戻し、ユーザー承認へ送る**。
失敗した試行・作り直した fixture も累計に数える(「数え直して閾値を回避する」余地を作らない)。

| 対象 | 回数 |

## 各 fixture が持つべき記録項目

不足があるものは corpus に採用しない。

1. 生成元 payload(モデル / tool に何を出させたか。真正は取得手順)
2. redaction 済みの生 PTY ストリーム + その sha256
3. フレーム境界(どのフレームで判定するか)
4. 期待セル属性
5. 期待判定(転送可否 / tool / args / 理由コード)
6. version manifest への参照
